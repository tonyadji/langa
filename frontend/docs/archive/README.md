# Archive — dashboard development history

Working documents produced while the dashboard was built with a spec-driven workflow
([Spec Kit](https://github.com/github/spec-kit)). They are kept for history and are **not kept up to date**:
some of them describe the earlier username / password authentication, replaced since by OpenID Connect.

| Path | Content |

| [`speckit/`](speckit/) | Spec Kit templates, constitution, agent prompts and analyses |
| [`IMPLEMENTATION_STATUS.md`](IMPLEMENTATION_STATUS.md) | Progress report per phase |
| [`.failing-tests.md`](.failing-tests.md) | Test failures tracked during the first user stories |
| [`RELEASE-NOTES.md`](RELEASE-NOTES.md) | Notes of the first containerised deployment |
| [`BROWSER_COMPATIBILITY.md`](BROWSER_COMPATIBILITY.md) | Browser check report (generated by `scripts/verify-browsers.sh`) |
